# Start here

This is an [Obsidian](https://obsidian.md/) vault that documents the [Dataview Pagination](https://github.com/mnaoumov/obsidian-dataview-pagination/) plugin by demonstrating it. A big `Dataview` result is drawn one page at a time, so the note stays fast and short.

The plugin works on top of [Dataview](https://community.obsidian.md/plugins/dataview), so install and enable `Dataview` in this vault first. Its query blocks show as plain code until you do.

## Your first minute

Open [01 Tables and lists](<./01 Tables and lists.md>). Each view there has 120 results, and below each one are the page controls.
